✅ WhatsApp AI Shop Assistant

A smart WhatsApp business assistant that chats with customers like a real human — answers questions, shares product photos, speaks in any tone (English, Pidgin, Yoruba), remembers customer preferences, and automates orders & delivery.

Built for:

✅ Phone sellers
✅ Ecommerce stores
✅ Restaurants & food vendors
✅ Service businesses
✅ Any business that sells through WhatsApp

🚀 Features

✅ Human-like chat responses
✅ Typing animation (looks real, not robotic)
✅ Learns & remembers customer preferences
✅ Order flow: add to cart → checkout → address → delivery confirmation
✅ Sends voice notes 🎤
✅ Sends product pictures 📸
✅ Multi-language (English, Pidgin, Yoruba e.t.c)
✅ Works 24/7 — no human needed

Coming soon:

⚙ PDF invoice sending
⚙ Auto-reply to missed messages
⚙ Support for videos, product catalogs, location sending
⚙ WhatsApp Groups support

🛠 Tech Stack

Node.js

Baileys (WhatsApp API)

Memory system (per user storage)

Local session auth

🔧 Installation (Developer Use)

🚧 This project is actively in development.

git clone https://github.com/samuelayanshina/whatsapp-ai-bot.git
cd whatsapp-ai-bot
npm install
npm run dev


Scan the QR code and your bot connects automatically ✅

🔐 Important

Create a .gitignore file:

node_modules/
auth_info/
media/
data/
.env


This prevents your WhatsApp session and private files from leaking publicly.
